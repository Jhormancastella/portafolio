## Sobre el proyecto

Sitio adaptable con contenido dinámico y un panel de administración para actualizar el portafolio.

## Ejecutar localmente

```bash
git clone https://github.com/Jhormancastella/portafolio.git
cd portafolio
```

Copia `js/config.example.js` como `js/config.js`, completa las claves de Firebase y Supabase, y sirve la carpeta con tu servidor local favorito.
